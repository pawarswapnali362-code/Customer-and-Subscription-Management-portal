# Demo capture checklist

Capture real screenshots from the running Next.js portal and save them in this folder before final submission:

- `login.png` — admin sign-in screen and demo credential hint.
- `dashboard.png` — customer-type metrics, partner allocation, issue counts, and recent activity.
- `customers.png` — customer filtering and record list.
- `partner-profile.png` — purchased / activated / remaining allocation counts.
- `issues.png` — issue filtering and status resolution flow.

Suggested 45–60 second walkthrough: log in with demo credentials; review the dashboard; open an organization profile and users; view partner allocations; show activation status and remaining count; record or update a payment; resolve an issue and show the resolved date.
